# Import policy

The four forks remain independent sources. This repository initially stores only provenance and review tooling; do not copy or publish their exercise text, tests, walkthroughs or solutions automatically.

- **Exercism Python**: MIT; preserve copyright/license and source attribution. Inspect exercise-specific notices before importing.
- **learn.python**: MIT; preserve copyright/license and attribution. Keep walkthroughs and solutions inaccessible to students and the Guide.
- **C1 Code Crunch Convos**: GPL-3.0; do not combine its content into a differently licensed distributed compilation without determining the obligations and intended licensing arrangement.
- **30 Days of Python**: no root LICENSE was found during initial review. A public fork is not a license grant. Obtain explicit permission or verify a valid applicable license before redistribution.

## Release gates

1. Review original license and upstream commit.
2. Curate prerequisites and remove duplicates by objective (never silently discard provenance).
3. Review starter code, instructions and any external assets.
4. Supply verified, isolated, server-owned tests and an execution policy.
5. Separate solutions, answer keys and audit material from learner/Guide payloads.
6. Validate AI Auditor question and grading policy.
7. Only then set learner_release to true.

The generated catalog is a **candidate inventory**, not the final teaching sequence. Never unlock a task based only on catalog presence.
